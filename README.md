# READwy Render deployment

This repository contains the deployable static site for READwy.

The files at the repository root are copied from `public\index.html` and `public\` in the main READwy project.

## Render settings

- **Environment:** Static Site
- **Build Command:** leave empty
- **Publish Directory:** `.`

No build step is required because `index.html` and all `resources` are already included.
